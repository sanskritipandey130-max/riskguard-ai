RISKGUARD AI – PROJECT DETAILS

+--------------------------+--------------------------------------------------------------+
| FIELD                    | DETAILS                                                      |
+--------------------------+--------------------------------------------------------------+
| Project Name             | RiskGuard AI                                                 |
| Tagline                  | Detect risks. Predict impact. Take action.                   |
| Project Type             | AI-powered Risk Management Platform                          |
| Target Users             | Businesses, startups, and project teams                      |
| Problem                  | Businesses often discover risks only after they become       |
|                          | serious problems such as cash-flow issues, customer churn,   |
|                          | supplier disruption, or missed deadlines.                    |
| Solution                 | An AI-powered platform that detects, analyzes, scores,       |
|                          | prioritizes, and manages business risks.                     |
| Risk Categories          | Financial, Operational, Market, Cybersecurity, Compliance,   |
|                          | Customer, Supply Chain, Project/Deadline                     |
| Risk Score               | Probability (1–5) × Impact (1–5) = Score 1–25                |
| Risk Levels              | 1–5 Low | 6–10 Medium | 11–15 High | 16–25 Critical          |
| Risk Matrix              | Visual 5×5 risk matrix                                       |
| AI Risk Agent            | Monitor → Detect → Analyze → Prioritize → Recommend →        |
|                          | Act → Monitor                                                |
| Action Center            | Tracks Pending, In Progress, Completed, and Dismissed        |
| What-If Simulator        | Simulates revenue growth, expense growth, churn, and cash    |
|                          | reserve changes                                              |
| Mitigation Plan          | AI-generated 30-day plan divided into four phases            |
| AI Risk Report           | Executive summary, top risks, trends, and mitigation plan    |
| Demo Mode                | One-click NovaCart demo with realistic business data         |
| Risk History             | Category filters and risk trend charts                       |
| Frontend                 | React 18, Vite, Tailwind CSS, Recharts, Lucide React,        |
|                          | React Router                                                 |
| Backend                  | Node.js + Express                                            |
| Database                 | MongoDB + Mongoose                                           |
| AI                      | Google Gemini API                                             |
| Risk Engine              | Deterministic rules engine for reliable risk scoring         |
| AI Layer                 | Gemini enriches explanations and recommendations             |
| Fallback System          | Deterministic fallback when AI/API is unavailable            |
| Deployment               | Vercel + Render + MongoDB Atlas                              |
| Main APIs                | Health, Projects, Risks, Actions, AI Agent, Simulation,      |
|                          | Reports, Risk History                                        |
| Future Scope             | Multi-user authentication, document upload, scheduled       |
|                          | analysis, alerts, historical charts, custom rules           |
+--------------------------+--------------------------------------------------------------+
